Feature overview: Close four confidence gaps.

The current workflow protects facts and privacy, but the test boundary, target-role lifecycle, public contract, and deployment guidance do not yet prove the complete promise.

Real-stack proof

Current browser tests replace every API response. A new test must run the compiled app, FastAPI, parser, schemas, rewrite validation, and generator with no external model call.

Editable target

The user must change the job description after upload. The reducer must make all earlier derived output stale or unusable before reuse.

One contract

Documentation must include project-bullet tailoring. The unused JSON ingestion route must leave unless a verified client needs it.

Safe delivery

The lockfile must resolve the high nanoid advisory. Production must stay private through a provider gate or remain local.

Purposeful motion

A stage handoff and three short acknowledgements must explain progress and causality. Motion must not own state or delay focus.

Success outcome

One repeatable local test drives the built SPA through a real FastAPI process and fake Gemini boundary, then verifies the generated DOCX and repeated download. The user can change the target without another upload, derived state cannot cross that change, one ingestion route remains, the production advisory is resolved, deployment fails closed, and motion explains only real workflow state.

Dependencies and assumptions

The plan uses the current runtime, test, state, and hosting seams. It does not assume a new platform service.

Required dependencies

  • Python 3.11 or newer and the current Python set, including python-docx and development-only reportlab.
  • Node 22 or newer and Playwright Chromium.
  • The existing get_gemini_service dependency-override seam.
  • gsap as the only new production package.
  • A hosting-provider access gate for private production. Vercel Standard Protection alone is not sufficient for the production domain.

Working assumptions

  • The supplied resume stays outside Git and enters only through BEAT_ATS_INTEGRATION_RESUME.
  • CI generates a non-private synthetic PDF at runtime with reportlab. No PDF fixture or ignore exception is added.
  • The fake service returns fixed validated extraction and analysis data, creates alternatives from selected source bullets, and never creates a Google client.
  • The JSON ingestion route has no supported external consumer. Its removal is an accepted breaking API change and one coherent contract unit.
  • Provider access controls remain an operational prerequisite and cannot be enforced by vercel.json alone.

Add purposeful GSAP motion

One verification handoff, three causal acknowledgements, and complete reduced-motion state.

Motion thesis

Source enters, facts settle, wording is accepted, and a file becomes ready. Motion shows that handoff. It does not reward a score or decorate reading.

Work

  1. Use a forward and backward GSAP stage and step-marker timeline of about 650 ms with at most 12 px movement.
  2. Use separate 180 to 240 ms analysis, apply, and completed-DOCX targets. Analysis must not replay stage motion. Truth readiness must not trigger export completion.
  3. Scope and clean every context during Strict Mode replay, rerender, interruption, cancellation, and unmount. Clear inline transform and opacity after completion or reduced motion.
  4. Test normal forward and backward start and final computed styles.
  5. Interrupt a transition and assert one final stage, one current step, and no stale inline style.
  6. Under reduced motion, assert computed opacity 1, transform none, empty inline motion styles, and stable top and left positions immediately and after one frame.
  7. Under Strict Mode replay, interruption, and unmount, assert that GSAP reports no active tween for each owned target, inline transform and opacity are empty, and only the current stage is present. Do not assert an internal cleanup call count.
  8. Test acknowledgement isolation and completed-DOCX triggering.
  9. Leave hover, focus, button, accordion, and drag-over behavior in CSS. Update the design contract and stable screenshot waits.

Exit

Forward, backward, interrupted, reduced-motion, Strict Mode, isolation, and export-completion tests pass. Focus stays immediate, no stale style or active owned tween remains, 320 to 1280 px layouts do not overflow, and one Impeccable detector run is resolved or recorded.
